# Touch comparison preparation

Execution waits for Phase E to finish. First inspect saved-pose wrist signals with `followup_touch_diagnosis.py`; it cannot run before E is marked complete. This is descriptive analysis, with no fitted controller and no new episodes. The true position only labels the saved readings afterwards. Incoming observation row t is paired with saved post-transition geometry row t-1. One first resting partial-overlap sample per episode avoids counting adjacent readings as separate episodes. The script also shows observed wrench clipping and component/position associations; failure of one mechanical estimate alone does not establish absence of every possible signal.

The blind search is fixed before seeing any touch data: an Archimedean spiral with 0.5 mm between turns, a 0.2 mm per-axis aim-nudge cap and the existing 3 mm guess cap. A changing angular increment keeps the requested step near its cap as radius grows. It starts around the current guess after observed contact, the existing ten-reading stall test, and observed height below 1 mm. It pauses while depth progresses and holds when the learner episode ends. It never changes the frozen policy, robot-action rule, camera, test schedule, seeds or success definition. Only the aim guess is changed.

The hand comparison has 500 test-only episodes at seed 123 and zero practice. The initialized neural network is never trained and never selects the aim; its Q output is not interpreted. The trace records the hand routine's actual applied aim nudge. Report success, start/success/final guess error, insertion steps, average episode peak force and timeouts. Save the complete final trace locally, not in git. Pure hand routines go in their own reference table and are not learner settings or final-choice candidates.

After the signal diagnosis, implement and run the torque and four-sided methods only if wrist readings supply a usable cue, as the plan requires. If they do not, record the evidence and contact-model limitation and run the blind spiral alone. No hand test has run during this preparation.

Teacher experiments remain conditional on a hand method coming within 10 percentage points of the zero-error reference. If that condition holds, use the specified 40/160, 20/180 and 80/120 fill/learner splits, own-episode labels and 20-reading memory, and compare hand-only, network-only and fallback-assisted behavior. Every trained configuration retains one 200-episode ledger, including teacher fill; evaluations never feed learning. All touch-trained networks remain ineligible for fresh selection even if evaluated without their teacher.

If more than one hand method qualifies as a teacher, select the highest success on the prescribed hand test, then the simpler routine for an exact tie (spiral, torque, four-sided probe). The teacher predictor receives the full 20-reading window, with the existing input scaling and network width. The movement addition requires the network-only view to meet the earlier working-aim criteria on five seeds: success above the normal floor beyond spread and a closer guess at success on paired episodes. A high fallback-assisted score alone cannot trigger that addition. These conditional choices were logged before any touch result.
